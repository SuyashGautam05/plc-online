Quick Reference

Tag prefixes:

I: → Physical Input  ·  O: → Physical Output

B: → Internal Bit (memory relay)  ·  N: → Numeric Register

T: → Timer  ·  C: → Counter

Rung layout (fixed):

Contacts always sit on the left, Functions (Timer/Counter/Math/CMP/Move/Scale) sit in the center, Coils always sit on the right. New elements are placed into the correct zone automatically.

Series & parallel wiring:

Contacts can no longer be combined with AND/OR gate blocks. Instead use the Connections tools: Vertical Line creates a new parallel branch (OR); Horizontal Line adds another parallel path to the nearest branch. Add NO/NC contacts inside each path to build series (AND) × parallel (OR) logic.

Placing elements (drag & drop only):

1. Drag an element from the palette

2. Drop it on the dashed "Drop here" zone at the end of a rung, or inside a parallel branch path

3. Timers, Counters, Compare, Math, Move & Scale open their settings immediately so you can set the value

4. Click any placed block again to edit it later

Run mode:

Once you press RUN the program structure is locked — you can still toggle switches to test the logic, but you must press STOP before adding, deleting or editing elements.

Set / Reset:

RESET always takes priority over SET on any given scan, so a live RESET input reliably turns an output off even if a SET input is also active — this avoids the old ambiguous latch behaviour.
